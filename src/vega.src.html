              Configuration

              Engine

              This hosted deck thinks with Claude, on your own Claude account. To run it on a private model on your own hardware, use the standalone file: it has the same interface and connects to Ollama, LM Studio, llama.cpp or any OpenAI-style server.

              Works with Ollama (http://localhost:11434/v1), LM Studio (:1234/v1), llama.cpp, vLLM, or anything that speaks /chat/completions. Also works with hosted gateways such as OpenRouter (https://openrouter.ai/api/v1); with a hosted gateway your messages go to that service and the model's provider. Free models only applies where the service lists prices.

              Web tools

              With web tools on, VEGA can consult Wikipedia and a weather service directly, and search the web and read pages through your relay. A request leaves this browser only when VEGA uses one of those tools.

              Identity

              Behaviour

              When allowed to speak up, VEGA gives an arrival briefing once a day, warns about low power or a lost connection, and reports when a sentry spots a change.

              Voice

              VoiceBella · generated in this browser

              Bella is a speech model that runs on your own device: about 90 MB is fetched once, then nothing spoken leaves the browser. Until it has loaded, replies are text only.

              The browser's built-in recognition (Chrome, Edge) sends audio to the browser vendor. For fully offline voice, choose the local Whisper endpoint (/audio/transcriptions). Wake word listens for the assistant's name.

              Sync across devices

              Sync keeps tasks, notes, memory, protocols, sentries, timers, conversations and the Library the same on every device that has the code. It is encrypted in this browser with a key made from the code before it leaves; the relay stores only scrambled data. Anyone with the code can read it, so treat it like a password.

              Desktop app

              Installed, VEGA opens in its own window from your desktop, dock or taskbar. With background alerts on, your relay keeps your timers, sentries and protocol schedules and notifies this device when one is due, even when VEGA is closed. A scheduled protocol is run by the relay itself, from a snapshot of your tasks, notes and memory that this device syncs to it, and the result arrives as the notification.

              Data

              Conversation, tasks, notes and memory are kept in this browser only.
